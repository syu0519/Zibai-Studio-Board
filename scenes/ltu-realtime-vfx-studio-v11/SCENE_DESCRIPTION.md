# 主場景與設備的製作描述

## 空間主體

主視角位於靠後側走道上方，俯看開闊的綠色攝影地坪。地坪延伸至背牆前，以半徑約 1.25 m 的連續四分之一圓弧向上翻起，消除垂直牆面與地板的硬折線。背牆保持大面積無柱遮擋，右後方堆放有獨立接縫的綠色箱體。綠幕不是一張含照片的平面；弧面、牆與地板皆可產生視差和受光。

雙側高架走道沿長牆展開。走道由下方斜撐與立柱承托，表面是逐條木面板；黑灰立柱連接細橫桿，最上方為棕色扶手。設備區與行走區以欄杆界定，後右側留有接地階梯。走道高度、寬度與樓梯屬影像估算，沒有把全景投影造成的曲線當成彎曲建築。

白灰牆體上方排列帶波褶的灰綠窗簾，下緣有突出牆面的空調箱及深色出風格。兩道水平管線沿牆延伸，並與天花吊桿、燈具形成細尺度層次。天花以縱橫格樑劃分白色板塊，板下分布黑白追蹤標記和小型吊燈。標記是原創示意圖案，沒有聲稱支援真實追蹤系統的識別碼。

後側補全設備操作區與出入口。此面的完整排列是依其餘照片推估，不代表每個節點都被拍到。室內建築保留頂面與背面，可從棚內環繞，未使用預覽專用隱藏牆。

## CamMate 參考式搖臂

搖臂基座位於 `[-1.8,0,2.1]`。兩道橫向輪梁、四輪、中央輪架和升柱構成接地支承。升柱頂端是水平旋轉節點；上方俯仰軸連接前長後短的桁架臂。兩根縱向樑由交錯斜撐和短橫接件組成，黑色結構件與銀色連接件分出材質層次。

前端延伸约 6.65 m，後端约 2.1 m；尾部配重逐片堆疊並帶金屬側緣。中部抬高的拉索支點向前後端分出細索，外側保留控制纜線。這些尺寸是場景配置值，不是任何 CamMate 型號的正式規格。

前端採獨立的水平補償節點、pan 節點及 tilt 節點。展示動畫先改變臂架，再反向補償遙控頭基架，攝影機才做小幅轉向。攝影機有主機、側板、肩上提把、電池、天線、外接取景器、多段鏡頭、通透開孔的遮光斗與紅色 tally。光學錨點位於遮光斗前方，可供宿主掛接真正的 Three.js 相機。

旁邊另設站立式遙控台，兩側為操縱握把，中央有示意讀值屏。角色可在站位面向台面，雙手對應左右握點；另一操作站設在配重尾端。站位保持落地，尾端手部目標則隨臂架運動。

## Orbiter 與 SkyPanel

Orbiter 以藍銀配色燈體、可交換光學口與 U 型架辨識。燈頭前方是套環和同心口緣，後方是散熱片、控制屏、旋鈕與接孔，上方保留提把和天線。支架兩側的傾角鎖緊件與可俯仰燈頭分件建模；伸縮燈架具有套管、鎖扣、三支撐腳、拉撐、腳輪與配重袋。電源盒置於低處，控制握點附近另有小型示意遙控面板。

SkyPanel 以 S60-C 官方 645×300 mm 發光口尺寸作為一項比例依據，其餘外殼與支架為近似重建。正面有黑色邊框、白色柔光面和四邊遮扉，背板排列散熱肋及控制面；燈頭由 U 型架支承在同型燈架上。面光源隨燈頭一起移動，避免只讓發光面旋轉而照明仍留在原位。

两台 Orbiter 的聚光照明投向中央表演區；SkyPanel 面光補足左右受光。天花另有三組面光源維持棚內基礎照度。標準 WebGL 矩形面光不投射陰影，本版以兩盞 Orbiter 的陰影補足設備接地關係。光色參數是視覺插值，不是校準色溫或廠商光度曲線。

## 工作站與中央留白

後方桌組採四段工作台，桌面、櫃體、腳輪、螢幕底座、導播按鍵與 T-bar 各自成形。音訊區排列十二路推桿和旋鈕，左右配置鍵盤滑鼠。兩側機櫃具有多層面板、把手與輪座，備用箱以金屬角條圍住深色箱體。桌前保留四張空椅；沒有使用任何人物幾何、人物貼圖或照片中的人像。

中央追蹤地墊約 5.8×4.4 m，規律小標記對應影像中的追蹤工作區。表演區附近僅放定位十字；主要線束沿側前緣行走，返送屏及燈架留在两側。設計目的是讓虛擬角色能在綠幕前表演，或從外部角色系統進入控制台操作。

## 動態原則

32 秒閉合循環只作用於搖臂、遙控頭與燈光小幅變化。建築、輪座、桌椅、線槽保持不動。人工設定 API 後自動退出展示模式；時間前進不會覆寫控制值。關閉動態時回到固定展示姿勢。螢幕內容屬静態 DEMO，不會冒充真實多機位監看訊號。
