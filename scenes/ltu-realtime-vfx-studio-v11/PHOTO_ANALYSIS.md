# 影像分析與重建範圍

使用圖一決定「綠幕、攝影搖臂、導播台、燈架群及側走道」的主次關係；圖二補充清空棚內後的弧牆與天花；兩張截圖補充反向工作區、空調及窗簾；全景用於確認左右延續。

| 影像證據 | 實作 | 不確定或補設計 |
|---|---|---|
| 挑高棚、綠地板、大片綠牆和圓弧接地 | 真實 3D 牆／弧面／地坪 | 整棚暫定 24×22×8.5 m，非测绘 |
| 側走道、金屬欄杆、灰白牆、窗簾空調 | 雙側完整建築與服務設施 | 柱距、走道及出入口尺寸估算 |
| 格樑天花和黑白追蹤板 | 格樑、板片、原創追蹤示意標記 | 不複製真實識別碼，不保證識別能力 |
| 中央長搖臂與後方配重 | CamMate 參考式桁架、輪座及遙控頭 | 型號不可辨識，未聲稱精確 CAD |
| 多種燈具和柔光設備 | 依使用者指定增加 Orbiter 和 SkyPanel | 並非聲稱照片內每盞燈都是這些型號 |
| 多機位工作站、監看與地面線路 | 導播桌、音訊台、返送屏、線束 | 示意 UI、設備数量與位置經取景調整 |
| 多張照片中有人 | 全部省略 | 空椅保留，不含人物 |

原照片的亮斑、綠色溢光與廣角／全景變形不直接烘進材質。以動態受光和幾何重建空間，避免人物或相機換角度後仍看到固定照片陰影。材質仍為程序化與示意貼圖，未達到照片復刻品質。

此版為 E2 室內完整環境；D3 設備近拍為目標，已做輪廓、組件及操作接口，但不宣告工業級精度。A2 以面光、聚光、陰影及環境反射構成；無額外塵霧、人物、雨雪或不相關裝飾。
